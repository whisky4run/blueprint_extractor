# 実装サマリー（本日）

## 概要
建築図面PDFのパーツ切り出しアプリに対して、AzureCU連携の実用性向上・UI拡張・出力改善を中心に改修した。

## 主要な実装内容
1. 検出エンジンの切り替え実装
- OpenCV切り出しとAzureCU切り出しを切り替え可能化。
- アップロード時の方式指定と、プレビュー画面からの再解析に対応。
- セッションごとに実行方式・実行ログ（処理時間、件数、失敗理由）を保持。

2. AzureCU検出結果の取り扱い強化
- AzureCU API呼び出しを `analyzeBinary` ベースに整理。
- `result.fields` 形式と `result.contents[].fields` 形式の両方を扱えるように対応。
- `source` 座標のページ寸法スケーリングを実装し、座標系差異を吸収。
- 実行時のAzureCU生レスポンスJSONをセッション配下へ保存する処理を追加。

3. タイトル起点のパーツ領域拡張
- AzureCUが返すタイトル矩形のみで切り出すのではなく、OpenCVで検出した罫線セルに連結してパーツ全体へ拡張。
- タイトル位置（上/下/左/右）を設定可能化し、同一図面内で統一方向として拡張ルールを適用。

4. 図面ヘッダの分離（除外しつつ保持）
- 図面ヘッダ位置（上/下/左/右）を設定可能化（デフォルト: 右）。
- AzureCU結果に図面ヘッダ相当項目が含まれても、切り出し対象 `parts` から除外。
- 除外した項目は `header_items` として保持し、将来のテキスト活用に備える構造へ変更。

5. ダウンロード出力の改善
- ZIPにPNGだけでなく `result.json` を同梱。
- `result.json` に方式、メトリクス、検出結果、ヘッダ項目、設定情報を記録。
- 実行時に保存したAzureCU生JSONを `azurecu_result/*.json` としてZIP同梱。
- ダウンロードボタン文言を「結果ZIPダウンロード」に変更。

6. PDF指定画面のUI見直し
- 設定項目増加に合わせ、画面を2カラム（設定/ファイル）構成へ再設計。
- レスポンシブ対応として狭幅時は1カラムに自動切替。

7. Analyzerの動的取得・選択
- AzureCU Analyzer一覧取得APIを追加（ボタン押下時のみ取得）。
- 起動時自動取得を避け、必要時のみ取得する設計に変更。
- フロント側で取得結果と選択中Analyzer情報を保持（localStorageキャッシュ）。
- 実行時に `analyzerId + apiVersion` を選択して解析可能化。
- `.env` の Analyzer設定は未選択時のフォールバック用途に整理。

8. プレビュー描画安定化
- 画像読み込みイベント依存で赤枠が消える問題を修正。
- `onLoad` 以外に `complete` / `requestAnimationFrame` / `ResizeObserver` でサイズ同期し、赤枠描画を安定化。

## 補足
- 主要変更はバックエンド（FastAPI/Python）とフロントエンド（React/TypeScript）の両方に跨って実施。
- Docker再作成まで行い、実行環境に反映済み。
