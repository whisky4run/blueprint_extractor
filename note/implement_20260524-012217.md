# 実装サマリー（2026-05-24 01:22:17）

## 概要
AzureCU 連携の安定化に向けて、入力を PDF 直接送信から OpenCV 切り出し画像送信へ切り替え、さらに PDF レンダリング解像度を調整可能な 300DPI 既定へ変更した。

## 実装内容
1. AzureCU 入力方式の変更（PDF → 画像）
- `backend/app/cu_detector.py` を拡張し、ページ画像から図面ヘッダ領域とコンテンツ領域を切り出して AzureCU に送信する方式へ変更。
- AzureCU 生JSONは `contents/header` の各入力画像とオフセット情報を含む形で保存するよう改善。
- AzureCU の source から得た座標を、切り出し画像座標から元ページ座標へオフセット補正する処理を追加。

2. 図面ヘッダ分離処理の強化
- OpenCV のセル検出結果を使ってヘッダ矩形を推定し、ヘッダ位置（上下左右）に応じてコンテンツ矩形を算出するロジックを追加。
- ヘッダ候補が得られない場合のフォールバック矩形も実装。

3. PDF 画像化の DPI 見直し
- `backend/app/pdf_converter.py` を修正し、固定 150DPI から `PDF_RENDER_DPI` 環境変数ベースへ変更（既定 300DPI）。
- DPI は 72〜600 の範囲でクランプし、不正値時は既定値へフォールバック。
- 画像出力ディレクトリの自動作成を追加。

4. 設定・ドキュメント更新
- `.env.example` に `PDF_RENDER_DPI=300` を追加。
- `APPROACH.md` の DPI 記述を 300DPI 既定に更新。

## 検証
- `python3 -m compileall backend/app` 成功。
- `docker compose exec -T backend sh -lc 'python -m compileall app'` 成功。
- Docker 上で PDF 画像化の解像度が 300DPI 相当（例: 4963x3509）になることを確認。
- 切り出し後のコンテンツ画像が Studio 確認画像に近い解像度帯へ改善（例: 4004x3509）。
